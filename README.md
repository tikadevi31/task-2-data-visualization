#  Task 2: Data Visualization and Storytelling

## Overview
This project presents an interactive Tableau dashboard built using the Sample Superstore dataset. It focuses on transforming sales data into meaningful business insights through effective data visualization.

## Tool
- Tableau

## Dataset
- Sample Superstore

## Dashboard Includes
- Profit by Region
- Sales by Category
-  Monthly Sales Trend
-  Discount vs Profit
-  Sales by State
-  Top 6 Products

## Key Insights
- Technology has the highest sales.
- West region generates the highest profit.
- Sales increase over time.
- Higher discounts often reduce profit.
- California records the highest sales.
- A few products contribute most of the revenue.
